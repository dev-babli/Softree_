# ATLAS Knowledge Repository

Numbered taxonomy — every file is an atomic, interconnected knowledge asset.

## Pipeline

```
Internet → Research Agent → Scraper → Cleaner → Summarizer → Fact Checker
→ Knowledge Extractor → Pattern Engine → Knowledge Files (.md) → Knowledge Graph
```

## Folders

- `00_constitution/` — Constitution: Thinking principles, quality gates, agent rules
- `01_company/` — Company: Softree vision, mission, positioning, ICP
- `02_consulting/` — Consulting: Delivery methodology, engagement models
- `03_business/` — Business: Business models, ROI, transformation economics
- `04_strategy/` — Strategy: Product strategy, roadmaps, category design
- `05_sales/` — Sales: Enterprise sales, negotiation, procurement
- `06_marketing/` — Marketing: Demand gen, funnels, campaigns
- `07_copywriting/` — Copywriting: Messaging, headlines, conversion copy
- `08_design/` — Design: Visual design, design systems, taste
- `09_ui/` — UI: Components, states, interface patterns
- `10_ux/` — UX: Information architecture, flows, usability
- `11_psychology/` — Psychology: Buying psychology, trust, persuasion
- `12_seo/` — SEO: Search optimization, intent, on-page
- `13_geo/` — GEO: Generative engine optimization
- `14_aeo/` — AEO: Answer engine optimization
- `15_llmo/` — LLMO: Large language model optimization
- `16_ai/` — AI: AI strategy, governance, enterprise AI
- `17_rag/` — RAG: Retrieval augmented generation
- `18_agents/` — Agents: Agentic systems, MCP, orchestration
- `19_architecture/` — Architecture: System design, cloud, DevOps
- `20_performance/` — Performance: Web perf, Core Web Vitals, optimization
- `21_security/` — Security: App security, compliance, AI safety
- `22_accessibility/` — Accessibility: WCAG, inclusive design
- `23_competitors/` — Competitors: Competitive intelligence profiles
- `24_industries/` — Industries: Vertical-specific knowledge
- `25_case_studies/` — Case Studies: Proof patterns, win stories
- `26_frameworks/` — Frameworks: Proprietary consulting frameworks
- `27_prompt_library/` — Prompt Library: Reusable agent prompts
- `28_report_templates/` — Report Templates: Audit and executive report structures
- `29_scoring/` — Scoring: Rubrics and scoring systems
- `30_playbooks/` — Playbooks: Step-by-step consulting playbooks
- `31_patterns/` — Patterns: Reusable extracted patterns

## Commands

```bash
npm run atlas:knowledge search "query"
npm run atlas:ingest
npm run atlas:improve
```
