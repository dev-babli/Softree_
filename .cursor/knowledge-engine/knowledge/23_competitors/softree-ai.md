## Summary

Kore.ai Artemis (May 21, 2026) is the primary competitive and design reference for Softree's `/agentic-ai-platform` page-forge workstream.

- **Artemis edition** — AI-programmable agent platform with ABL, Arch, Dual-Brain architecture
- **Governance-first** — observability and policy enforcement before production deployment
- **Neutral positioning** — model/cloud agnostic vs hyperscaler-native platforms
- **Softree repo lineage** — `softree-agentic-exact/`, `design-reference/kore/`, k2 motion runtime
