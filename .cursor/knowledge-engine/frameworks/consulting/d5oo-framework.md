## Summary

Five phases every Softree engagement and consulting narrative follows. Every recommendation includes business impact, technical impact, ROI, difficulty, and priority.

## Core Concepts

| Phase | Activities |
|-------|------------|
| **Discover** | Business, processes, goals, stakeholders, systems, pain points |
| **Diagnose** | Root cause, workflow mapping, tech/website audit, AI readiness, gap analysis |
| **Design** | Roadmap, architecture, automation, AI strategy, tech selection, KPIs |
| **Deliver** | Implementation, integration, testing, training, docs, deployment |
| **Optimize** | Analytics, monitoring, continuous improvement, ROI measurement |

## Decision Framework

```
Start → Discover complete? → Diagnose → Design approved? → Deliver → Optimize loop
```

Use on: client engagements, service page structure, audit reports, sales process.

## Failure Modes

- Skipping Diagnose → wrong technology prescription
- Deliver without Design KPIs → unmeasurable ROI
- Optimize without baseline → cannot prove value

## Metrics

- Time per phase
- Client satisfaction at phase gates
- ROI measured in Optimize phase
- Recommendation acceptance rate
