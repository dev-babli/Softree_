## Summary

Kore.ai is Softree's primary **design and motion benchmark** for `/agentic-ai-platform`. Product positioning shifted to **Artemis** (May 21, 2026) — AI-native, governance-first enterprise multi-agent platform.

## Artemis Platform (May 2026)

**Launch:** May 21, 2026 — Kore.ai Agent Platform Artemis edition

**Core innovations:**
- **Agent Blueprint Language (ABL)** — compiled, validated agent definitions
- **Arch** — AI-driven agent design
- **Dual-Brain** — autonomous reasoning + deterministic rule-based execution

**Positioning:** Deploy production-ready multiagent systems in days (not months) with governance, observability, and operational control **before** agents go live.

**Go-to-market:** Initially Microsoft Azure; integrates Foundry, Agent 365, Entra ID, Microsoft Graph, Teams.

**Analyst recognition:** Gartner MQ Leader (Enterprise Conversational AI); Forrester Wave Leader; Everest Group Leader Agentic AI PEAK Matrix 2026.

**Competitive bet:** Neutral, model-agnostic layer vs hyperscaler lock-in (Microsoft, Salesforce, ServiceNow).
