```
│  │              │  │                                      │  │

│  │              │  │                                      │  │
│  └──────────────┘  └──────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

**Sidebar Width**: 256px (expanded), 64px (collapsed)
**Top Bar Height**: 48px
**Content Padding**: 24px

### Responsive Behavior

- **Desktop**: Sidebar visible, full layout
- **Tablet**: Sidebar collapsible, content adjusts
- **Mobile**: Bottom sheet navigation, simplified views

## Responsive Considerations

### Desktop (1280px+)
- Full sidebar visible
- Two-column layouts
- All keyboard shortcuts available

### Tablet (768px - 1279px)
- Collapsible sidebar
- Single-column primary views
- Touch-friendly targets

### Mobile (< 768px)
- Bottom navigation
- Stacked layouts
- Simplified command palette
- Sheet-based modals
