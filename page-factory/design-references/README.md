# Design References — drop zone

Put anything here that should influence the design direction:

- **HTML source** of websites you admire → save as `<site-name>.html`
- **Screenshots** → `.png` / `.jpg` / `.webp`
- **URLs + notes** → add lines to `urls.md` (one URL per line, optional note after `—`)
- **Prompts / written direction** → any `.md` or `.txt` file

The design-researcher agent reads EVERYTHING in this folder at intake, extracts
concrete patterns (layout systems, type scale, motion language, color logic,
section rhythm), and merges them with live web research into the design brief.

Subfolders are allowed and encouraged, e.g. `design-references/heroes/`,
`design-references/case-study-layouts/`.
