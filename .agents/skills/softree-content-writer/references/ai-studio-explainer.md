# What is an "AI Studio"?

Use this when the user asks about AI Studio or wants a new page. **Do not assume Softree has this product.**

## Industry meaning

An **AI Studio** is usually a **vendor workspace** where teams design, build, test, and ship AI applications in one place. It is a product surface, not a consulting engagement.

Typical features:

| Capability | What users do there |
| --- | --- |
| **Prompt / agent builder** | Visual or low-code design of agents and prompts |
| **Model playground** | Try models, compare outputs, tune parameters |
| **Workflow / orchestration** | Chain tools, agents, APIs, human approval steps |
| **Eval & test** | Run test suites, regression on prompt/model changes |
| **Deploy & observe** | Publish to channels; logs, traces, cost, quality metrics |
| **Governance** | Roles, secrets, policy, audit |

## Examples (not Softree products)

| Name | Who owns it |
| --- | --- |
| Google AI Studio | Google — Gemini prototyping |
| Azure AI Studio / Foundry | Microsoft — model + agent tooling |
| Copilot Studio | Microsoft — M365 agent builder |
| Kore Agent Platform / Artemis | Kore.ai — enterprise agent platform |

## Softree's actual position

Softree **implements** on these surfaces. Softree does **not** ship a competing "AI Studio" SaaS.

Correct framing:

- "We build agentic solutions **in** Copilot Studio and Azure AI"
- "Offshore delivery for agent programs your IT team can govern"
- "From discovery to production in weeks" (with approved stats)

Incorrect framing:

- "Softree AI Studio — our agent platform" (unless user explicitly creates a **branded services** landing page and accepts it is not a product)
