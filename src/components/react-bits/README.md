# React Bits (local copy)

Animated React components from [React Bits](https://github.com/DavidHDev/react-bits) by David Haz.

- **Variant:** TypeScript + Tailwind (`TS-TW`)
- **License:** MIT + Commons Clause (see upstream repo)
- **Sync:** `npm run react-bits:sync` (requires `_vendor/react-bits` clone)

Components live in category folders under this directory. Generated files:

- `catalog.ts` — browse metadata
- `registry.ts` — dynamic imports for previews

Preview in Sanity Studio: **React Bits** tool, or `/showcase/react-bits`.
