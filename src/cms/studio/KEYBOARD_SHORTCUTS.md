# Studio keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `⌘K` / `Ctrl+K` | Open command palette (search documents) |
| `Esc` | Close command palette |
| `⌘S` / `Ctrl+S` | Save document (Sanity default) |
| `⌘Z` / `Ctrl+Z` | Undo |
| `⌘⇧Z` / `Ctrl+Shift+Z` | Redo |
| `P` | Open Presentation tool (when focused in structure) |

Command palette searches case studies, blog posts, marketing pages, service lines, and tags.
